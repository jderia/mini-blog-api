# API

Il sito usa JSONPlaceHolder per recuperare post e autori.

## Post


Endpoint:

https://jsonplaceholder.typicode.com/posts

Campi usati:

- id
- title
- body
- userId

## Autori

Endpoint:

https://jsonplaceholder.typicode.com/users

Campi usati:

- id
- name
- email
- company.name

Gli autori vengono mostrati nella pagina autori.html.
