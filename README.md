# Mini Blog API

Questo progetto è un piccolo sito web blog che mostra tramite le api dei post e degli autori.

I dati vengono presi da JSONPlaceHolder.

## Funzionalità

- pagina Home
- pagina Post
- pagina Autori
- caricamento dati da API
- grafica con Bootstrap

## Tecnologie usate

- HTML
- CSS
- Bootstrap
- JavaScript
- API JSONPlaceholder

## API usata

Post:

https://jsonplaceholder.typicode.com/posts

Autori:

https://jsonplaceholder.typicode.com/users
